# Generative AI Use Declaration

Generative AI was used as a support tool during the design, development, analysis, and documentation of this road-injury dashboard. The tool used in this project work was GitHub Copilot in Visual Studio Code.

AI assistance was used to:

- explore visualization options and discuss chart selection, visual encodings, color use, accessibility, interaction, and limitations;
- generate, explain, and refine parts of the Vue, JavaScript, D3, and CSS implementation, including data loading, charts, controls, navigation, and responsive layouts;
- troubleshoot implementation issues and suggest ways to test the dashboard;
- draft and revise parts of the academic report, reflection materials, chart descriptions, and usability-evaluation text; and
- suggest research sources and citation details for the report.

AI-generated suggestions and drafts were treated as assistance, not as authoritative results. Project members reviewed and adapted outputs to fit the dashboard and the supplied data. The dashboard was built and selected interface changes were checked in a browser. The group remains responsible for reviewing the final code and interface, validating all reported figures and interpretations against the supplied workbook and source documentation, and checking every citation against its original publication before submission.

The project uses the supplied and cleaned road-injury workbooks; AI was not used to create or replace the dataset. The source notation `N.P.` was treated as not applicable rather than as zero. AI did not conduct interviews, peer reviews, or user testing, and did not generate observed evaluation feedback. Any claims about feedback or usability results in the submitted report must be based on evidence actually collected by the group.

This declaration describes project-level AI assistance and does not imply that all members used AI equally or performed identical tasks. Each member should confirm that it accurately reflects their own contribution and disclose any additional tools or uses required by the unit's academic-integrity policy.
